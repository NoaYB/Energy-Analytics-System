# Abnormal Devices Dashboard

A React platform that demonstrates the UI and logic for an Abnormal Devices Dashboard.

- **Stack:** React, TypeScript, Vite, SCSS.
- **Features:** Client-side pagination, simulated AI insights, interactive badges.
- **Note:** This is a UI simulation. It uses mock data and does not connect to a live backend database or real OpenAI APIs.

## How to Run Locally

Navigate to this directory and run:

```bash
npm install
npm run dev
```
